# scoop-luoto

Scoop bucket for [luoto](https://github.com/eetu/luoto): dev sandboxes that contain
supply-chain attacks. Windows.

```powershell
scoop bucket add luoto https://github.com/eetu/scoop-luoto
scoop install luoto
luoto setup
```

`bucket/luoto.json` is written by luoto's release workflow; changes belong in
[`packaging/scoop`](https://github.com/eetu/luoto/tree/main/packaging/scoop).
